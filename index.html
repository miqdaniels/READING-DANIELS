Home  /  Settings

Settings

Practice reads before recording
How many times the student slides and reads on their own before the read that records.
Pacer on the final read
Default is Tap: the student taps to move the yellow phrase along at their own speed. Switch a student to Pacer when they read accurately and are ready to build speed — the phrases advance on their own, and a Pause button lets them catch a breath.
Teams (for the scoreboard)
Put each student on a team. At the end of class, open the Scoreboard to show team standings. Use the dash to leave a student off a team.
Class codes (save across devices)
Enter each class’s code once on this computer so the Scoreboard counts every student’s device. Give students their class link with the code in it (?c=CODE) in Canvas, so they never have to type it.

Home  /  Status

What’s real right now

Working

  • Teacher records the word alone and the whole sentence, in your own voice, for all 27 words.
  • Student hears the word, hears the sentence, slides a finger pacer that lights the current word and dims the ones behind it, reads it out loud, and records a final read.
  • The final read saves as a file the student turns in through Canvas.
  • Colors and dark/light are student-selectable and remembered on the computer.
  • Teacher can Export all recordings to one file, and Load that file onto any other computer so your voice is there too.
  • No text-to-speech anywhere — the only voices are yours and the student’s.

Partly working / honest limits

  • Tapping a single word replays the whole sentence so the student hears that word in context. Per-word audio for every word isn’t recorded — the “Hear the word” button covers the target word only. True tap-any-word audio would mean recording every word separately; that’s a later choice, not faked here.
  • The listen sweep moves evenly across the sentence for the length of your recording. It is a pacing guide, not exact word timing.
  • Microphone and file save need the page opened from a real web link (Canvas), not a file on the desktop.

Not built (on purpose)

  • Automatic pronunciation scoring — never faked. The student and teacher listen and judge.
